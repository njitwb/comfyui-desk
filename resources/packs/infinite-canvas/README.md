# 无限画布 · 全能力整合包

导入方式：ComfyUI Desk → 「整合包」页 → 选择本 zip。

## 组件
- image: 图像基础（T2I / I2I / 局部编辑）
- text: 文本生成 / 反推
- video-omni: 全能参考视频（6 规格）
- video-frame: 首尾帧视频（6 规格）
- audio: MiniMax Music 03
- face-refine: H3 人脸精修
- depth: ReShot 深度视频

## 模型
模型默认从 HuggingFace / 魔搭按清单下载，不随包分发。

## 说明
comfyui-pack.json 是本包唯一描述文件，payload/ 仅放工作流与无法从云端获取的小文件。
